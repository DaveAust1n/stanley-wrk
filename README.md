# Metro Motors

React, TypeScript, Vite and Tailwind campaign frontend.

Run `npm ci` and `npm run build`. Campaign and vehicle placeholders are in `src/data.ts`.

This version is a preview: claims use browser session storage, not a database; payments and transaction verification are disabled. Configure approved campaign terms, privacy policy, vehicles and support details, and implement secure server-side claim storage and verification before collecting personal information or money.
